# GettingHome

A offline Medical Guide Application

## Getting Started

1. Clone the project
2. Download dependencies
3. Run project

### Run this code snippet to setup the project!
```
git clone https://github.com/danielsmirnoff/GettingHome.git
cd GettingHome
flutter pub get
flutter run
```
